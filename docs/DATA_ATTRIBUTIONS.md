# Referencias de países

`src/data/icaoCountries.json` adapta los códigos ISO alpha-3/alpha-2 del conjunto [ISO-3166-Countries-with-Regional-Codes](https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes), de Luke Duncalfe y colaboradores. Se añadió el código ICAO `D` para Alemania. Este archivo de datos adaptado se distribuye bajo [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), según la [licencia original](https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes/blob/master/LICENSE.md). Los nombres españoles se obtienen de `Intl.DisplayNames` del navegador.
